# UniMixins late-loader compile API

`UniMixins-0.2.1-late-api.jar` contains only the unmodified `ILateMixinLoader`
interface and `LateMixin` annotation from UniMixins 0.2.1's GTNHMixins module,
plus that module's original license, credits and README. It is compile/test-only
and must not be shaded into ReplayMod. The modpack supplies UniMixins at runtime.

Source artifact: `io.github.legacymoddingmc:unimixins:0.2.1`.
Original GTNHMixins source: https://github.com/GTNewHorizons/GTNHMixins/tree/2.1.13
UniMixins source: https://github.com/LegacyModdingMC/UniMixins
